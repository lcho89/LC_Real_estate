🔌 Load Real URA Transaction Data
Two ways to load real Singapore condo transaction data from the URA Data Service API (free account required).

Option A — Python script (recommended)

Fetches ~5 years of data, saves as ura_data.js in the same folder, then auto-loads on refresh.
pip install requests python fetch_ura_data.py
Place ura_data.js next to sg-condo-dashboard.html, then refresh this page.
or

Option B — Fetch directly in browser

Register for a free Access Key at eservice.ura.gov.sg/maps/api/, then generate a daily Token.
