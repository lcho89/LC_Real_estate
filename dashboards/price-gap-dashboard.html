🔄 Framework A — Price Reset (Implied NL PSF)
For each resale comp: resale PSF ÷ remaining lease × 99 = implied NL PSF. If implied NL < actual NL → resale has value.

📏 Framework B — $50/yr Gap Rule
For each comp: expected NL premium = $50 × age gap. Justified NL = comp PSF + premium. If post-harmonization, add 5%. Value = justified NL − actual NL.
