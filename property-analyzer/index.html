Comp settings

Window — how far back to pull comps. 12 months is freshest; widen to 24–36 for a quiet project. Size band — only comps within this % of your size count. Keep it at 10–15% for a common layout; widen it if the comps table comes back nearly empty.
When you need one: your project has no transaction history yet, so there is nothing to comp against. Pick an older, established project — same district or one MRT stop away, similar bedroom count, plenty of resale prints — and the full age-gap ladder runs. That is exactly Eric's method: Treasure at Tampines for Pinery, Costa Del Sol for Vela Bay. Leave this blank for a resale; the project's own prints are always the better comp.
Age gap = your TOP year − the benchmark's TOP year. Eric adds $50 psf for every year the benchmark is older. Fill in both TOP years and this computes itself; type a number to override.
